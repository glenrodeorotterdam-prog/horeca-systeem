# Horeca Systeem — iOS MVP
Eerste klikbare MVP voor dashboard, voorraad, keuken, wijn, dranken, leveranciers en rapporten.

## TestFlight
Dit project is voorbereid als Expo/React Native project. Een echte TestFlight-build moet met een Apple Developer/App Store Connect-account worden ondertekend en geüpload; dat kan niet rechtstreeks vanuit deze chat.

## Volgende bouwstap
Database + authenticatie + echte voorraadmutaties + leveranciersprijzen + slimme weeg-/camera-flow.
